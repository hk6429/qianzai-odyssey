# 千載字旅

以原創中國國風潑墨插畫與頭身 1:1 的 Q 版文人，將先秦到清代的詩詞曲文串成冒險學習網站。玩家化身「補卷人」，逐章找回失落的千載書卷。

## 目前版本

- 10 個朝代、100 個小章、10,000 段去除標點仍不重複的原文，共 5,989 篇作品。
- 詩、詞、曲、古文、辭賦與駢文；包含經典名句與延伸選讀。
- 每題保留作者、篇名、完整原文及固定版本來源連結。
- 先看原句卡，再做四選一續句；到期複習交替採選擇與輸入回憶。
- 答錯重練、提示、離開接續、整批完成才入帳；三次跨日獨立複習加一次輸入回憶才列為熟練。
- 任意章節可試讀 5 段，不增加進度。主要旅程依序前進。
- 本機存檔、JSON 備份、手機版；沒有登入或雲端同步。
- 原創故事與 AI 插畫為虛構包裝，不是歷史原話或肖像。

## 本機執行

需要 Node.js 22 以上；網站沒有執行期依賴，不需要安裝套件。

```sh
npm test
npm run build
npm start
```

開啟 `http://127.0.0.1:4208/`。加上 `?test` 會使用獨立的測試存檔，不影響正式本機進度。

## 資料與來源

請見 [來源說明](SOURCE-NOTICES.md)、[題庫統計](docs/corpus-audit.json) 與 [逐作品原文核對](docs/source-verification.json)。

僅引用古代原文，沒有搬用現代翻譯或賞析。原文轉為繁體並移除括注；異文、傳統歸屬及版本標點仍須留意。自動比對能驗證來源一致性、唯一性與配題正確，不能取代逐題教師審訂與古籍校勘。

重建題庫需要 Python 3 與 OpenCC。已將選定資料提交到版本庫，日常啟動不必重建。

```sh
python3 scripts/restore-sources.py
python3 scripts/build-corpus.py
python3 scripts/verify-sources.py
npm test
npm run build
```

還原程式從固定版本下載研究用原始資料並檢查 SHA-256；約 150 MB，置於被 Git 忽略的 `sources/raw/`。僅最後選用的古代原文進入公開成品，網站發布採明確檔案白名單。

## 檔案

- `app.js`：地圖、故事、試讀、練習、原文閱讀與本機儲存。
- `engine.js`：進度、答題、間隔複習與備份驗證。
- `story.js`：十位文人、十卷故事、百章標題。
- `data/`：萬題、作品原文與課程序列。
- `scripts/build-corpus.py`：來源轉換、分期、去重、配題與選項產生。
- `assets/`：網站使用的 WebP 插畫；[提示詞](docs/art-prompts.md)。
- `docs/`：來源、建置與驗證紀錄。

## 沉浸式故事漫遊

滿版場景搭配透明背景兩頭身旅伴，逐句閱讀故事後接受任務。行旅目錄收納朝代／景點與章節；未解鎖章節可探看與試讀，正式學習仍依序進行。首頁與預習不改寫學習成果，原本機存檔與匯入匯出格式保持相容。首站採獨立高解析場景，其餘沿用原水墨地景圖集。
